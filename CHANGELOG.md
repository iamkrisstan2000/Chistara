# Changelog

## 1.1.0 — October 2026

- Added the CD Days artwork visualizer with a reactive glowing outline.
- Added persistent sorting for Music and FM collections.
- Enforced a DPI-aware 1024 × 600 minimum window size.
- Improved unified search with cached artist/album groups, bounded top-result ranking, and lightweight input debouncing.
- Updated executable and project authorship to KnightWin.
- Simplified the README and added an optional Ko-fi support link.
- Preserved existing playback, radio, themes, audio effects, artwork, migration, and taskbar-safe maximization behavior.

## 1.0.0 — October 2026

- First stable release of Chistara for Windows 11.
