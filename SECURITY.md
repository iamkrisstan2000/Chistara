# Security policy

## Supported version

Security fixes are provided for the latest published Chistara release. The current supported line is **1.1.x**.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub’s **Security → Report a vulnerability** private reporting flow for this repository. Include:

- the affected version;
- reproduction steps or a minimal proof of concept;
- the security impact;
- any suggested mitigation; and
- whether the report may be credited publicly.

Do not include real credentials, private media, identifying local paths, or third-party personal information. The maintainer will acknowledge a complete report when possible, investigate it, and coordinate disclosure with the reporter.

## Scope

Reports concerning Chistara’s source or packaged executable are in scope. Availability, content, or policy issues belonging solely to Radio Browser, MusicBrainz, Cover Art Archive, IPWhoIs, broadcasters, Windows, or NuGet dependencies should also be reported to the responsible upstream project.
