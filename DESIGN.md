# Design mapping

The supplied 1128 × 796 blank canvas established the shell rather than content. Chistara keeps its key proportions and tone:

- 32 px custom title bar with native Windows caption behavior. A `WM_GETMINMAXINFO` hook uses the nearest monitor’s physical work-area rectangle when maximized, preserving taskbars on every edge and avoiding custom-frame clipping under PerMonitorV2 DPI. The same hook reapplies the exact 1024 × 600 WPF minimum as DPI-scaled native track dimensions, so resizing stays enabled without allowing custom chrome to collapse into a title-bar strip.
- 44 px command bar with left-aligned Home/Music/FM tabs, a mathematically centered unified search field, and a compact Settings gear at the far right. Symmetric `1 : 2 : 1` columns keep search independent from unequal side controls. Every top navigation action uses compact matching accent-aware hover and selected boxes without a redundant underline.
- The title bar and command bar share one uninterrupted surface; there is no separator between them.
- Contextual left pane: 224 px expanded and 56 px collapsed.
- Persistent 72 px transport surface at the bottom, including cached track artwork when available. It and the complete top area are independently layered over Acrylic at 5% translucency in Dark mode and 2% translucency in Light mode. A separate 6 px neutral gradient fades downward from navigation into content without touching the title bar; the player retains its soft neutral 1 px / 6 px-blur upward shadow.
- Near-black neutral layers with restrained accent color and no accidental olive/green cast.
- Thin low-contrast separators, 6–10 px container radii, compact typography, and generous empty space. Music covers, station artwork, history/search thumbnails, grouped artwork, and their fallbacks are fully circular.
- Segoe UI Variable Text and Segoe Fluent Icons on Windows 11.
- Chistara’s official identity uses the supplied rounded deep-navy tile, cyan-to-violet equalizer bars, and crisp white music note with a subtle cyan stem highlight. The original transparent 256 px PNG is preserved byte-for-byte, while dedicated 16/20/24/32/40/48/64/128/256 px ICO frames keep the same mark clean from the title bar through Explorer’s largest icon view.

The window requests the Windows 11 `DWMSBT_TRANSIENTWINDOW` system backdrop for real Acrylic. The root stays transparent, the main content owns its neutral layer, and the top and bottom materials sit directly over the backdrop so their requested alpha is not compounded by another full-window fill. `DWMWA_BORDER_COLOR` is set to `DWMWA_COLOR_NONE` to prevent a wallpaper-derived green or other colorized outer outline. Lite Mode deliberately changes the system backdrop to lower-cost Mica and applies documented safety limits to exceptionally large scans; core playback remains available.

The shell is one WPF window with contextual views rather than multiple windows. This keeps navigation immediate, memory use predictable, and the supplied canvas visually intact. Home has separate Overview and Recently Played destinations rather than one anchored scroll; its history is a roomier card grid capped at 12 items. Overview refreshes its greeting on every visit and presents separate Local and Worldwide FM recommendation cards from small, cached directory pools. Device discovery lives in Music. The Settings context has four destinations—Visual, Player, Troubleshoot, and About—and only the selected destination is visible. About pairs the product identity with KnightWin authorship, the AI acknowledgement, and the October 2026 date. Every contextual-pane destination now uses the same checked-state mechanism as the top tabs: a quiet accent-low hover pill and an accent-medium selected pill with a full accent border. Its two-way `IsChecked` binding to the destination model keeps exactly one active item highlighted until navigation changes. The 5 px horizontal / 4 px vertical inset remains readable in the 224 px expanded state and forms a clearly centered selection around the icon in the established 56 px collapsed rail. Home and Settings keep page-level scrollbar tracks near the right edge while retaining their content inset; Music and FM prioritize equal 28 px effective margins around their main content. All Songs and FM use the same long-left-visualizer / 300 px right-list layout. FM also matches All Songs vertically—header, helper row, then an uninterrupted content row—with no footer reserving or clipping bottom space. Their compact 54 px rows reclaim width with 30/38 px action-art columns, 12 px titles, 9.5 px metadata, and full-title tooltips; FM follows the same play-first row hierarchy. Artists, Albums, and Devices retain equal left/right surfaces. Artist and Album collections use an adaptive uniform grid: up to four columns on the supplied wide canvas, automatically reducing columns below a 158 px useful cell width. A fixed two-line title slot uses character ellipsis for overflow, keeps count baselines aligned, and exposes the complete name through a tooltip; compact circular art preserves card balance. Music/FM lists have no rounded outer shell; only purposeful row states and individual library cards remain. Custom drop-downs retain high-contrast text in both themes.

Music rows support both direct play from a compact button on the left and double-click anywhere else on the selected row. Media-folder editing stays in Settings › Player, while a compact sort icon beside Rescan opens persistent Alphabetical, Recently Played, Date Added, and Date Modified choices. Sorting is applied after the current search filter and feeds the ordered playback queue; artist and album cards derive non-alphabetical order from their newest or most recently played member. FM mirrors this pattern beside Refresh stations with persistent Alphabetical, Recently Played, and Date Added choices for Local and Worldwide lists. Accent resources are dynamic, so switching accents immediately refreshes generic artwork, pane states, controls, and the Home hero instead of leaving stale green-tinted surfaces. Windows-derived System accents retain both hue and saturation while sharing a 0.18 relative-luminance floor in Light and Dark modes; dark colors are channel-scaled before any tinting can reduce chroma. Near-black neutral DWM values with no recoverable hue use standard Windows blue rather than becoming grey or remaining black, while Light mode still bounds overly bright accents. RGB accent mode uses slowly interpolated WPF brushes rather than a timer-driven redraw, keeping the animation subtle and inexpensive. The bottom play/pause control is circular, with a dedicated two-stop animated gradient wave in RGB mode. Local music adds Shuffle before Previous and a compact Repeat off/all/one menu after Next; these controls disappear for FM. Queue-end and crossfade logic honor the selected repeat mode, and disabling Shuffle restores ordered navigation around the current track. Reverb retains its original 0–60% wet-mix control and restrained fixed feedback. Crossfade uses a continuous 0.5–2 second slider with no ticks or snap points; saved values are bounded to the 2-second maximum. All artwork uses an explicit `EllipseGeometry` clip—rather than relying on rounded borders—so rectangular source images stay truly circular. Artist and Album cards apply that ellipse to the complete 64 px composition (base, offset highlight, initials, and image), preventing the highlight from exposing a sharp rectangular edge. Home’s record-like circle shows current music artwork or a station logo when available and rotates only while playback is active.

The visualizer samples the post-EQ, post-reverb, post-volume signal and computes a 2,048-sample Hann-windowed FFT, waveform energy, bass energy, and adaptive beat onsets from a short in-memory ring buffer. Waves provides broad PS3-inspired ribbons, Modern Waves uses fine PSP-inspired strands, Topographic renders a reactive contour field, and Simple Spectrum uses minimal rounded glow bars with peak hold. CD Days uses the shared decoded now-playing artwork for music and FM, rotates it inside a clipped disc while playback is active, adds hub and reflective groove details, and shapes a multi-pass glowing outline from live spectrum, waveform, level, and beat values. All modes consume the live `AccentBrush`, including animated RGB. The selected style title is the only persistent chrome inside the card: it floats over the full-edge visualization with a restrained text shadow, while its quiet border and chevron appear on hover or while the selector is engaged. Once its popup closes and the pointer leaves, a dedicated 1.5-second idle timer clears only that interaction state and returns the control to its text-only title; lingering keyboard focus no longer pins the chooser chrome open. WPF-only FM fallbacks use WASAPI loopback analysis only for the duration of that playback; no sample is persisted. A visualizer subscribes to WPF’s composition clock only while its page is visible, skips work while the window is minimized, and runs inactive motion at 30 fps. Point arrays and FFT scratch space are reused, the Hann window and stable logarithmic band map are precomputed, and stream geometry is built without transient LINQ collections. Lite Mode continues to cap active rendering at 30 fps.

Worldwide FM data is consumed in 2,000-record pages and presented through a recycling, pixel-scrolling virtualized list as pages arrive. Each page appends only its new rows during discovery instead of copying the full accumulated catalog; the final normalized/sorted result still replaces the collection once. Music uses the same recycling strategy, and both lists keep one adjacent page realized for fluid wheel and touchpad scrolling. A bounded size-aware artwork cache complements container recycling so revisited rows reuse decoded images. Local FM merges geotagged nearby results with the complete healthy country directory, then prioritizes distance. This avoids forcing one oversized worldwide response while preserving access to the full normal-mode catalog.

Unified search caches artist and album summaries when the library changes instead of regrouping the complete catalog for every keystroke. A reusable query matcher tokenizes once, avoids per-item parameter arrays and combined strings, and keeps only the small best-ranked result set rather than sorting every match. A 110 ms local debounce coalesces rapid typing while Enter and Down flush pending work immediately; the existing 420 ms network debounce continues to prevent unnecessary FM directory requests.
